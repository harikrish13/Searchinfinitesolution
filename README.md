# Search Infinite — Client Website

Website designed and built end-to-end for **Search Infinite** (freelance client project): layout and styling, page structure, and client-side interactions.

## Built With

- HTML
- CSS
- JavaScript

## Structure

```
searchinfinite/
  index1.html   - Main page
  style1.css    - Site styles
  CSS/          - Additional stylesheets
  JS/           - Client-side scripts
  img/          - Image assets
```

## Run Locally

Open `searchinfinite/index1.html` in a browser, or serve the folder with any static server, e.g. `python3 -m http.server` from inside the `searchinfinite` folder.
